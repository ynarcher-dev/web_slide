# MVP 수동 확인 시나리오

> 자동화 검사(`pnpm validate`, `pnpm e2e`, `pnpm db:verify-rls`)가 모두 통과한 뒤,
> 사람이 브라우저에서 한 번 훑어 확인하는 절차다. 출시 전 1회, 그리고 발표 화면이나
> 슬라이드 유형을 바꾼 뒤에 다시 수행한다.
>
> 자동화가 이미 확인하는 것은 여기서 다시 세지 않는다. 이 문서는 사람 눈으로만 판단할 수 있는
> 것 — 화면이 실제로 어떻게 보이고 어떻게 느껴지는지 — 에 집중한다.

## 준비

- [ ] `.env.local`이 확인 대상 Supabase 프로젝트를 가리킨다.
- [ ] `pnpm db:push`가 `up to date`를 낸다.
- [ ] `pnpm build && pnpm start`로 프로덕션 빌드를 띄운다. 개발 서버가 아니어야 한다.
- [ ] 브라우저 두 개를 준비한다. 하나는 로그인용, 하나는 시크릿 창(비로그인 확인용)이다.

## 1. 로그인

- [ ] `/login`에서 이메일과 비밀번호로 로그인된다.
- [ ] 틀린 비밀번호를 넣으면 오류 문구가 보인다.
- [ ] 로그인 후 `/presentations`로 이동한다.

## 2. 목록

- [ ] 프레젠테이션이 없으면 빈 상태와 만들기 버튼이 보인다.
- [ ] `새 프레젠테이션`으로 제목을 넣어 만들면 편집 화면이 열린다.

## 3. 공통 설정

- [ ] 편집 화면 헤더에서 제목을 고치면 목록에도 반영된다.
- [ ] 브랜드 색상, 표지 tint, 푸터 텍스트, 페이지 번호 표시를 바꾼 값이 미리보기에 즉시 보인다.
- [ ] 새로고침해도 값이 유지된다.

## 4. 표지 슬라이드

- [ ] 표지 슬라이드를 만들고 제목과 발표자 이름을 넣는다.
- [ ] tint를 올리면 배경색이 흰색에서 브랜드 색 쪽으로 옮겨 간다.
- [ ] 로고가 표지 규칙대로 놓인다.
- [ ] 헤더의 저장 상태가 `저장 중` → `저장됨` 순으로 바뀐다.

## 5. 본문 슬라이드 네 유형

각 유형을 한 장씩 만들어 확인한다. 네 장 모두 페이지명, 대제목, 소제목, 로고, 푸터, 페이지 번호가
같은 자리에 있어야 한다.

- [ ] **본문(웹페이지)**: HTTPS URL을 넣으면 16:9 프레임 안에 웹페이지가 뜬다.
      `http://`나 잘못된 주소는 거부된다.
- [ ] **이미지**: 그림을 올리면 잘리지 않고 16:9 영역 안에 들어간다. 교체와 제거가 동작한다.
      10MB를 넘는 파일이나 지원하지 않는 형식은 오류 문구가 나온다.
- [ ] **HTML**: 붙여 넣은 HTML이 그려진다. 편집 중 좌우 패널이 영향을 받지 않는다.
- [ ] 목록 썸네일에 네 장이 각각의 모습으로 보이고, 유형 이름(표지·본문·이미지·HTML)이 붙는다.
- [ ] 드래그로 순서를 바꾸면 페이지 번호가 다시 매겨지고 새로고침해도 유지된다.

## 6. 편집 중 콘텐츠 조작

- [ ] 미리보기에서 웹페이지 영역을 누르면 테두리가 초록색으로 바뀌고 안쪽을 조작할 수 있다.
- [ ] 영역 바깥을 누르거나 ESC를 누르면 조작이 꺼진다.
- [ ] 조작이 꺼진 상태에서는 미리보기를 눌러도 웹페이지가 반응하지 않는다.

## 7. 발표

- [ ] 발표 화면에 들어가면 리모컨이 잠깐 보였다가 접힌다.
- [ ] 접힌 뒤 마우스를 화면 위쪽으로 올리면 리모컨이 내려온다.
- [ ] Tab으로도 리모컨을 불러낼 수 있다.
- [ ] 방향키와 리모컨 버튼으로 앞뒤로 이동한다. 첫 장과 마지막 장에서 버튼이 비활성이다.
- [ ] 전체화면에서 슬라이드가 화면을 가로세로 100% 채운다. 검은 여백이 없다.
- [ ] 웹페이지를 조작한 뒤 마우스를 위로 빼면 리모컨이 다시 내려온다. ESC로도 돌아온다.
- [ ] 빠르게 여러 번 넘겨도 화면이 어긋나거나 멈추지 않는다.
- [ ] 시연하던 웹페이지 상태가 앞뒤로 이동한 뒤에도 남아 있다.

## 8. 공유 링크

- [ ] 공개로 바꾸고 링크를 복사한다.
- [ ] 시크릿 창에서 그 링크가 열리고 발표할 수 있다.
- [ ] 편집 UI나 발표 종료 링크가 보이지 않는다.
- [ ] 비공개로 되돌리면 시크릿 창에서 새로고침했을 때 더 이상 열리지 않는다.

## 9. PDF 내보내기

- [ ] PDF 내보내기 중 진행 상태가 보인다.
- [ ] 받은 PDF의 페이지 수가 슬라이드 수와 같고 순서가 같다.
- [ ] 표지 tint, 로고, 푸터, 페이지 번호가 화면과 같게 나온다.
- [ ] 웹페이지 영역이 정지 화면으로 들어가고, 그 자리를 누르면 원본 주소로 연결된다.
- [ ] 이미지와 HTML 슬라이드도 화면과 같은 모습으로 나온다.

## 10. 삭제

- [ ] 슬라이드를 지우면 확인을 묻고, 지운 뒤 인접 슬라이드가 선택된다.
- [ ] 마지막 슬라이드를 지우면 빈 상태가 보인다.
- [ ] 프레젠테이션을 지우면 목록에서 사라진다.
- [ ] Supabase Storage의 `slide-images`에서 해당 프레젠테이션 폴더의 파일도 사라졌다.
