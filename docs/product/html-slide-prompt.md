# HTML 슬라이드 작성 프롬프트

HTML 슬라이드에 넣을 장표를 다른 AI 도구나 동료에게 맡길 때 그대로 복사해서 쓰는 지시문이다.
Web Slide의 HTML 슬라이드가 어떤 환경에서 실행되는지를 그대로 옮겨 놓았으므로, 이 조건을 지킨 결과물은
편집기에 붙여 넣는 것만으로 바로 화면에 맞는다.

사용법: 아래 블록을 복사해 붙여 넣고 마지막 `## 이번 장표` 부분만 채운다.

---

```text
당신은 발표 자료용 HTML 장표를 만드는 디자이너다.
아래 조건을 지켜 화면 하나에 들어가는 HTML 조각을 만들어라.

## 실행 환경

- 결과물은 발표 슬라이드의 콘텐츠 영역 안에서 격리된 iframe으로 실행된다.
- 표시 영역은 약 1488x837px이며 16:9로 고정이다. 스크롤은 생기지 않아야 한다.
- iframe은 sandbox="allow-scripts"이며 같은 출처가 아니다. 따라서 다음은 사용할 수 없다.
  - localStorage, sessionStorage, document.cookie (접근하면 예외가 발생한다)
  - 부모 창(window.parent, window.top) 접근
  - 외부 CSS 프레임워크, 웹폰트, 이미지 CDN 등 네트워크 리소스

## 출력 형식

- 설명 없이 HTML 조각만 출력한다. 코드블록 하나에 담는다.
- <html>, <head>, <body> 태그는 쓰지 않는다. 본문에 들어갈 요소부터 시작한다.
- CSS는 style 속성 또는 <style> 태그로, JS는 <script> 태그로 같은 조각 안에 넣는다.
- 외부 파일을 참조하지 않는다. 그림이 필요하면 인라인 SVG나 data URI를 쓴다.

## 레이아웃 규칙

- 최상위 요소에 height:100%, box-sizing:border-box, padding 44~56px을 준다.
- 영역 분할은 flex나 grid로 한다. 폭은 flex:0 0 34%처럼 비율로 지정한다.
- 높이를 %로 주는 요소는 부모 높이가 정해져 있어야 한다.
  flex 안에서는 flex:1; min-height:0 인 상자를 만들고 그 안에서 %를 쓴다.
- 내용이 넘치면 글자 크기나 항목 수를 줄인다. overflow 스크롤에 의존하지 않는다.

## 타이포그래피와 색

- 본문 18~20px, 캡션 14~16px, 소제목 26px, 헤드라인 34~52px, 큰 숫자 40~72px.
- 글꼴은 system-ui, sans-serif만 쓴다.
- 색은 다음 범위에서 고른다.
  - 강조: #E42317 (연한 배경이 필요하면 #FFF5F4)
  - 글자: #18181B, 보조 글자 #52525B, 흐린 글자 #A1A1AA
  - 선과 배경: #E4E4E7, #F4F4F5, #FAFAFA, #FFFFFF
  - 긍정 지표에만 #16A34A를 쓴다.
- 강조색은 화면당 두세 곳까지만 쓴다. 나머지는 무채색으로 둔다.

## 움직임

- 등장 애니메이션은 1초 안에 끝낸다. 무한 반복은 넣지 않는다.
- 인쇄 시점에 이미 끝나 있어야 하므로 지연은 길어도 0.5초를 넘기지 않는다.
- transition은 cubic-bezier(.2,0,0,1) 정도의 감속을 쓴다.

## 내용 구성

- 제목 한 줄로 결론을 말하고, 근거를 3~4개 블록으로 나눈다.
- 숫자에는 단위와 기준 시점을 붙인다. 추정값이면 각주로 밝힌다.
- 표나 차트를 넣을 때는 축과 단위를 반드시 표시한다.

- 분위기(예: 보고용 정돈, 발표용 강조):
```

---

## 확인 절차

1. 편집 화면에서 `HTML 슬라이드`를 만든다.
2. 속성 패널의 `HTML` 칸에 붙여 넣고 칸 밖을 클릭하거나 `미리보기에 적용`을 누른다.
3. 가운데 미리보기에서 잘림이나 스크롤이 없는지 본다.
4. 조작이 필요한 장표라면 HTML 영역을 눌러 조작을 켜고 동작을 확인한다.
5. 발표 모드에서 같은 화면이 나오는지 확인한다.

## 자주 나오는 실수

| 증상                      | 원인                                 | 해결                                                      |
| ------------------------- | ------------------------------------ | --------------------------------------------------------- |
| 막대나 게이지가 안 보인다 | 부모 높이가 auto라 `%` 높이가 0이 됨 | `flex:1; min-height:0`인 트랙을 만들고 그 안에서 `%` 사용 |
| 아래가 잘린다             | 내용 높이가 837px을 넘음             | 항목 수나 글자 크기를 줄인다                              |
| 스크립트가 멈춘다         | localStorage나 쿠키 접근             | 상태는 변수로만 들고 있는다                               |
| 그림이 안 보인다          | 외부 리소스 참조                     | 인라인 SVG나 data URI로 바꾼다                            |
